# Agent builders — evidence inbox

Drop quick evidence captures here if you don't know where they belong yet.

- Prefer hands-on notes/screenshots as evidence when possible.
- Use the CLI to generate a correctly formatted file:

```bash
product-os new-evidence --domain agent_builder --source_type hands_on --source_name "Notion Custom Agents" --slug inbox --title "Notion: first agent run"
```

Then move the file into `hubspot/`, `notion/`, `viktor/`, or `zapier/` once you know.
