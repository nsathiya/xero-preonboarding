# Agent builders — observation matrix notes (index)

We keep the `evidence/` folder strict (raw evidence only). The “matrix”
is primarily a **capture + comparison tool**, so it lives in `notes/`
and you promote strong entries into evidence files when ready.

## Per-product matrix notes

- `notes/agent-builders/matrix/hubspot.md`
- `notes/agent-builders/matrix/notion.md`
- `notes/agent-builders/matrix/viktor.md`
- `notes/agent-builders/matrix/zapier.md`

## Promotion rule (notes → evidence)

When a row feels important:

1. Create an evidence file in `evidence/agent-builders/<product>/`
2. Put the screenshot/quote/step-by-step in **`## Raw evidence`**
3. Put your interpretation + questions in **`## Notes`**

This keeps provenance clean while still letting you work quickly.
